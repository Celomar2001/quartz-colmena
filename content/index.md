# Archivo Colmena

Bienvenido al **Archivo Colmena**, una base de conocimiento pública creada para organizar, preservar y consultar información mantenida originalmente en un documento colaborativo de Google Docs.

Este sitio funciona como una versión navegable, ordenada y de lectura rápida del contenido principal del documento. Su propósito es facilitar el acceso a la información, separarla por idioma y presentarla en un formato compatible con Obsidian y Quartz.

---

El contenido está dividido en distintas secciones según el idioma disponible en el documento original:

Cada página corresponde a una pestaña del documento fuente y se actualiza mediante un proceso automatizado.

---

## Fuente de información

La información publicada aquí proviene del documento público de Google Docs que se encuentra en constante modificación.

Este sitio no reemplaza el documento original, sino que lo transforma en una estructura más cómoda para lectura y navegación. Seguimos en desarrollo

---

## Actualización del contenido

El contenido de esta página puede cambiar con el tiempo, ya que está pensado para sincronizarse periódicamente con el documento original.

Cada archivo generado incluye metadatos internos con la fecha de actualización, lo que permite revisar cuándo fue sincronizada por última vez cada sección.

---

## Objetivo del proyecto

El objetivo de este proyecto es construir una **wiki viva**, donde la información pueda mantenerse centralizada de forma comoda. Las tecnologías que estoy usando son las siguientes:

- Google Docs API
- Obsidian
- Quartz
- GitHub Pages

De esta forma, el documento colaborativo puede seguir siendo editado en Google Docs, mientras que el sitio web se mantiene como una versión pública organizada y consultable.

---

## Nota

El contenido mostrado en este sitio depende del estado actual del documento fuente.  
Puede contener cambios recientes, traducciones en progreso o secciones todavía incompletas.
